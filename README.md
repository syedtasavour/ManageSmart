# ManageSmart

**Open Source Project Management Software (No Resell)**

ManageSmart is a **modern, responsive, React + TypeScript project management software** to streamline your team's workflow, manage tasks, and improve productivity.

---

## 🚀 Features

✅ Modern, clean, mobile-friendly Kanban interface  
✅ Built with React + TypeScript + Vite for speed  
✅ TailwindCSS for easy theming  
✅ Drag-and-drop task management (using `@dnd-kit`)  
✅ Redux for predictable state management  
✅ Axios for secure API integration  
✅ Semantic UI for consistent UI components  
✅ Designed for **internal and client deployments only (no unauthorized resale)**

---

## ⚡ Tech Stack

- **React 18 + TypeScript**
- **Vite** (fast dev server and bundling)
- **Tailwind CSS** (utility-first styling)
- **Redux + Redux Thunk**
- **Semantic UI React**
- **Axios**
